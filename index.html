        Google Sheets

        Keep a live copy of everything in your own Google Sheet. Each change syncs a few seconds later, and the sheet gets Entries, Bills and a Summary with a category chart. A new phone can restore from it.

        One-time setup on a computer

        1. Create a Google Sheet (go to sheets.new), then choose Extensions > Apps Script.
        2. Replace the code there with the setup script and click Save. To get the script, open on the computer and copy all of it.
        3. Choose Deploy > New deployment, pick Web app, and set Execute as: Me and Who has access: Anyone. Click Deploy. When Google says it hasn't verified the app (you made it yourself), choose Advanced, then Go to your project, then Allow.
        4. Copy the Web app URL (it ends in /exec), send it to this phone, and paste it below.

        Open sheet

        Changes sync a few seconds after you make them, whenever you're online. The Entries, Bills and Summary tabs are rewritten each time, so add your own tabs for anything else.
